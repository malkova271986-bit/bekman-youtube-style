# bekman-youtube-style

Навык для Claude: фирменный стиль YouTube-канала «ИИ для учёного и педагога» ([@elenabekman317](https://www.youtube.com/@elenabekman317)).

## Что внутри

- `SKILL.md` — сам навык: позиционирование, плейлисты, правила названий, шаблон описания видео, оба стиля обложек (палитры, шрифт, композиция, значки), баннер и фото профиля, контент-план.
- `examples/` — готовые материалы:
  - `foto_profilya_kniga.png`, `foto_profilya_II.png` — фото профиля 800×800;
  - `oblozhki/svetlye/`, `oblozhki/temnye/` — обложки 1280×720 в светлом и тёмно-синем стиле.

## Как пользоваться

Загрузите `SKILL.md` в Claude как навык. После этого достаточно написать, например: «Сделай обложку для видео о NotebookLM» или «Придумай название и описание для видео про ORCID» — результат будет в стиле канала.
